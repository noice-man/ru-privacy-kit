# RU Privacy Kit — Public Beta

Русскоязычный плагин WordPress для cookie-баннера, управления согласиями и подготовки юридических документов сайта.

**Текущая версия:** `1.0.0-beta.7` · **Статус:** Public Beta · **Лицензия:** GPL-2.0-or-later.

## Возможности

- Мастер установки с генерацией политики cookie, политики ПДн, условий использования и публичной оферты для платных сайтов.
- Пять адаптивных вариантов cookie-баннера; светлая, тёмная и наследуемая тема.
- Три режима аналитики: запуск после согласия, до отказа и расширенный Google Consent Mode.
- Загрузка Яндекс Метрики и GA4 средствами плагина и возможность изменения согласия.
- Защита существующих страниц WordPress от незаметной перезаписи.

## Ограничения

**Public Beta** не является юридической экспертизой. Плагин управляет только самостоятельно загруженными счетчиками; сторонние скрипты темы, плагинов и GTM требуют отдельной проверки. Перед применением на рабочем сайте рекомендуется резервная копия, проверка документов и сетевых запросов.

## Дистрибуция

Распространение: [ворд-пресс.рф](https://xn----ctbgf6biedka.xn--p1ai/). После публикации исходников GitHub Actions создаёт установочный архив и Release `v1.0.0-beta.7`.
